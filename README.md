# WhatsApp Auto Reply Extension

This Chrome extension automatically replies to messages on WhatsApp Web with a preset message.

## How to Use:
1. Clone the repository with this command:
   ```bash
   git clone https://github.com/willeam10101010-afk/Wz.git
   ```
2. Go to Chrome -> Extensions -> Enable Developer Mode.
3. Click 'Load unpacked', then select the folder `Wz`.
4. Open [WhatsApp Web](https://web.whatsapp.com/) in Chrome.
5. The extension will auto-detect and reply to messages.

## Notes:
- Make sure Chrome has permission for WhatsApp Web.
- Modify the `content.js` file to customize the responses.
